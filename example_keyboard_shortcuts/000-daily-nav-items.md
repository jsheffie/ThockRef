## General Daily Opening Things

| Key Seq | Result |
|---------|--------|
| ^ ⌘ c  | skhd: Open Chrome |
| ^ ⌘ x  | skhd: Chrome H-Work Profile |
| ^ ⌘ v  | skhd: Chrome TT-Work Profile |
| ^ ⌘ t  | skhd: Open Terminal|
| ^ ⌘ f  | skhd: Open Finder |
| ^ ⌥ →  | btt: Move window to right side |
| ^ ⌥ ←  | btt: Move window to left side |
| ^ ⌥ Enter  | btt: Make full screen window |
| ⌘ +  | macOS: make font bigger |
| ⌘ -  | macOS: make font bigger |
| ⌘ t  | tty: New Tab |
| ⌘ 1  | tty: First tab |
| ^ ← / ^ → | skhd: Navigate Desktop left/right |
| ^ ↓ / ^ ↑ | skhd: Navigate Desktop down/up |
