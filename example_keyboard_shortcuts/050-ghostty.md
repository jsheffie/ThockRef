# Ghostty Keyboard Shortcuts

```laptop-layout
    .-------------.
    | Shift ⇧     |
    |--------.----'-----.-------.
    | ctrl ^ | option ⌥ | CMD ⌘ |
    '--------'----------'-------'
```

## Clipboard

| Key Sequence | Result |
|---|---|
| `⌘` `C` | Copy to clipboard |
| `⌘` `V` | Paste from clipboard |
| `⌘` `⇧` `V` | Paste from selection |

---

## Font Size

| Key Sequence | Result |
|---|---|
| `⌘` `+` | Increase font size |
| `⌘` `-` | Decrease font size |
| `⌘` `0` | Reset font size |

---

## Tabs

| Key Sequence | Result |
|---|---|
| `⌘` `T` | New tab |
| `⌘` `⌥` `W` | Close tab |
| `⌘` `⇧` `[` | Previous tab |
| `⌘` `⇧` `]` | Next tab |
| `^` `⇧` `Tab` | Previous tab |
| `^` `Tab` | Next tab |
| `⌘` `1` – `8` | Go to tab 1–8 |
| `⌘` `9` | Go to last tab |

---

## Splits

| Key Sequence | Result |
|---|---|
| `⌘` `D` | New split (right) |
| `⌘` `⇧` `D` | New split (down) |
| `⌘` `[` | Go to previous split |
| `⌘` `]` | Go to next split |
| `⌘` `⌥` `↑` | Go to split above |
| `⌘` `⌥` `↓` | Go to split below |
| `⌘` `⌥` `←` | Go to split left |
| `⌘` `⌥` `→` | Go to split right |
| `⌘` `^` `↑` | Resize split up |
| `⌘` `^` `↓` | Resize split down |
| `⌘` `^` `←` | Resize split left |
| `⌘` `^` `→` | Resize split right |
| `⌘` `^` `=` | Equalize splits |
| `⌘` `⇧` `Enter` | Toggle split zoom |

---

## Windows

| Key Sequence | Result |

| `⌘` `⌥` `⇧` `W` | Close all windows |

|---|---|

## Selection

| Key Sequence | Result |
|---|---|
| `⌘` `A` | Select all |

| `⇧` `→` | Extend selection right |
| `⇧` `↑` | Extend selection up |
| `⇧` `↓` | Extend selection down |

## Text Editing

| Key Sequence | Result |
|---|---|
| `⌘` `→` | Move to end of line (`^E`) |
| `⌘` `←` | Move to start of line (`^A`) |
| `⌘` `Delete` | Delete to start of line (`^U`) |
| `⌥` `←` | Move word left |
| `⌥` `→` | Move word right |
