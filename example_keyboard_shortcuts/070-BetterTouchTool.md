```laptop-layout
    .-------------.
    | Shift ⇧     |
    |--------.----'-----.-------.--------------.
    | ctrl ^ | option ⌥ | CMD ⌘ | Space Bar ␣  |
    '--------'----------'-------'--------------'
```

## Section Name

| Key Seq | Result |
|---------|--------|
| ^ ⌥ →  | Move window to right side |
| ^ ⌥ ←  | Move window to left side |
| ^ ⌥ ↑  | Move window to top |
| ^ ⌥ ↓  | Move window to bottom |
| ^ ⌥ Enter  | Make full screen window |
