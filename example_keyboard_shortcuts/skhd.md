## Space Navigation

| Key Seq   | Result |
|-----------|--------|
| ^ →       | Move right within row (wraps at col 8) |
| ^ ←       | Move left within row (wraps at col 1) |
| ^ ↓       | Move down one row (+8 spaces) |
| ^ ↑       | Move up one row (-8 spaces) |
